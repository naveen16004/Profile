# ⚡ Naveen's Digital Portfolio
> "Logic meets aesthetic in a high-contrast digital world."

This is my personal workspace where I blend **Full-Stack Development** with creative UI/UX. It features a custom-built backend that tracks every interaction and alerts me instantly.

### 🛠️ The Tech Stack
* **Frontend:** React.js (Hooks, ScrollReveal, Typed.js)
* **Backend:** Node.js & Express
* **Database:** MongoDB (Mongoose Schema)
* **Notifications:** Nodemailer (Gmail SMTP Integration)

### 🚀 Key Features
* **Live Contact System:** Real-time form validation with automatic database logging.
* **Instant Alerts:** Integrated email triggers that notify me of new leads immediately.
* **Dynamic UI:** Smooth scroll animations and typing effects for a "live" feel.
* **The Yellow Bolt:** A custom-themed aesthetic representing energy and speed.
